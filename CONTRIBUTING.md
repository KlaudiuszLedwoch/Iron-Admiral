# Contributing to Iron Admiral

Help is welcome: bug reports, battle logs, balance notes, historical data corrections, code fixes and translations.

## How to contribute

- Bug reports and ideas: open an issue on GitHub or post on the Nexus Mods page. Attach `MelonLoader/Latest.log` or the "report a problem" package from the F10 panel when you can.
- Code and data changes: open a pull request on GitHub. Keep each change small and describe what it does and why.
- Historical data: give a source for every value (book, article or website).
